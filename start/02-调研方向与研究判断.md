> 整理日期：2026-09-21 ｜ 来源：2026-09-15~19 九轮调研（子代理交叉验证 + 原文核实标注），总档为 CVLearning `docs/learning/research/longtail-data-embodied-survey.md`。
> 证据等级：约 55 篇中约 30 篇【已核实】（子代理或本人抓取摘要页逐字确认），其余【搜索级】；引用数字与结论使用前需读原文。

## 1. 研究定位与核心判断

- **核心兴趣**："选择数据让长尾任务收敛更快"。
- **数据选择与重加权/重采样的本质区别**（已确认）：决策方式（子集选择 vs 权重分配）与问题前提（省预算 vs 纠偏）。
- **方向偏好**：以多模态长尾（图文预训练分布、VLM/MLLM 长尾适配、多模态 prompt 与跨模态表示）为主线；纯视觉、联邦、自动驾驶、MoE 仅作辅助对照或方法来源。
- **数据选择的准确定位**：若只是样本级加权，则重复重加权的历史；若改变训练集**信息结构**（去 head 冗余、保 tail 多样性），则是新空间。

### 1.1 用户自己的初步怀疑（2026-09-19，与机会地图并存的反方视角）

汇报文档中记录的个人判断：**数据选择对长尾任务的帮助可能比较有限**——一方面子集选择只能删冗余、删不出尾部缺失的信息；另一方面模型侧方案（如 LA）便宜且有效；Rethinking the Bias 的结论（训练时干预修不掉预训练偏差）也加强了这一倾向。

该怀疑与第 2、3 节的正面机会**并存**：机会 1 的设计（信息结构干预、类间预算、影响函数对准预训练弱类方向）正是对这条怀疑的可能回应路径。立项时应同时携带正反两方视角，用实验裁决，而不是预设结论。

## 2. 研究机会地图（四项，按"证据支持的空档 × 与已有知识衔接度"排序）

1. **长尾 × 影响函数数据选择（含类间预算）**：CVPR 2026 主会空档；组件文献齐备（CHIPS 打分 + NUCS 预算教训 + 质量门控先例）；关键设计维度 = per-class quota（类间配额）、删除风险控制（tail 删 5/20 张 = 25% 信息损失）、选择发生在哪个训练阶段。
2. **logit adjustment → 策略学习（具身）**：调研中标注出的事实空白；障碍 = 连续动作空间没有离散类先验；现有近似仅 Balanced BC 与 VLA-TMEE 两个概念邻居。
3. **影响函数的视觉 ↔ 具身对话**：CHIPS（视觉）与 ATHENA（具身）技术栈平行收敛（子空间 / 结构化 Hessian 近似），互相引用的空间已经打开。
4. **VLN 指令长尾**：未成流派（关键词分散），基准先行的空档。

## 3. 空档最终确认（机会 1 的竞品证据）

**"曲率-影响打分 + 显式长尾处理"组合在已核实文献中无人占据**——四个邻居各占一角，交叉格仍空：

| 邻居 | 占据的一角 | 缺的另一角 |
|---|---|---|
| CHIPS | 影响函数 + 轻量曲率打分 | 无长尾结构 |
| NUCS / Class-Proportional | 类间预算 | 打分无影响函数 |
| RCAP（UAI 2025，最接近） | 动态类预算闭式解 | 打分仍是类内 loss |
| Dharmasari 审计 | 指出 coreset 制造类不平衡 | 未给判据 |

两条互证：

1. LIFT 系全部延续工作（LIFT+、Sage、LT-Soups 等 10 篇摘要核实）均无样本选择——**"数据选择 × LIFT 骨架"组合接近空白**。
2. coreset × 长尾在顶会主会明确结合的仅 3~4 篇（RCAP UAI 2025、CSOR ICML 2026、ECS CIKM 2025、FairCore 待确认），2025 年前几乎空白、正在升温；纯 coreset 每年 30+ 篇。

## 4. 核心学术判断：coreset × Rethinking-the-Bias 怎么结合（2026-09-19，最重要的一条）

### 4.1 naive 叠加无意义

训练成本不是 Rethinking the Bias 的痛点——coreset 省训练侧预算，而该论文痛点在推理侧 3× FLOPs，**成本轴错位**；且其四个组件（因果调整、LA、多模型微调、融合）没有"数据排序"性质槽位。

### 4.2 真正有意义的三个组合位置

1. **数据选择作为参数不平衡的第三修正通道（最有价值）**
   该论文"参数不平衡不可修"的主张只覆盖 logit 修正与重采样两类干预，未测试**信息结构干预**（影响函数选择对准预训练弱类方向）。可检验假设：**单模型 + 面向预训练弱类的影响函数选择，能否恢复多模型融合（3× 推理代价买 +2.57）的大部分增益？** 三种结局均有价值：恢复 = 便宜的第三修正通道；不恢复 = 强化其边界条件；部分恢复 = 画出可修复性划分图。
2. **类预算公式的第二根轴**
   NUCS 按下游类难度分配预算；再加预训练先验轴（先验强的类下游少留、先验弱的类多留），构成两维非均匀预算。
3. **打分目标方向的去混杂**
   打分方向 u 用多模型 g_val 平均替代单模型（do-演算思想注入打分器内部）。

### 4.3 研究叙事一句话

"它说参数不平衡只能用 3 倍推理的集成修；我们检验更便宜的修法——选择正确的数据。"

## 5. 数据选择五路线与长尾特有缺口

**五路线分类**（2023–2026 跨会议约 20 篇）：

| 路线 | 代表 |
|---|---|
| 频率驱动 | CB sampling / DRW；LDAL 改预测频率 |
| loss-难度驱动 | CUDA（ICLR 2023）、Class-Difficulty（"频率 ≠ 难度"）、Difficulty-Net、NUCS |
| 梯度-influence 驱动 | IB Loss → GradTail → CHIPS（居中） |
| 距离-分布驱动 | ClipCov、RLDD、CLLS |
| 混合 | How Re-sampling Helps（背景质量判据） |

**长尾特有而 CHIPS 未处理的四点**：类间预算分配；频率与难度解耦；选择发生的训练阶段；质量门控先于效用打分。

**与"收敛更快"同族的省训练成本邻居**：效率大头在预训练 + 轻量适配这一代（LIFT / LPT）；省 epoch 的已有手段有 LORT（二阶段收敛监测）与 Decoupled Optimisation（成本减半），详见 `01` B10——它们与数据选择同属"省训练预算"族，是本研究主张的对照方法。

**2024–2026 coreset 五趋势中与本方向最相关的两条**：去训练化是最大方法学主轴（DUAL / ELFS / SubZeroCore / ZCore 都在攻击"先训一遍才能选"，CHIPS 站在主轴上）；选择副作用（公平性 / 类不平衡）成为新研究对象——与长尾结合的最主要通道。

## 6. 与 VLM 直接相关的结构判断

- **LIFT 之后的主线走向**：证明 FM 有用（LIFT / LPT）→ PEFT 变体精细化 → 组件理论反思（LA 在 FM 时代需要重估）→ **长尾定位从下游数据前移到预训练分布**（Neglected Tails、Rethinking the Bias 均在此）→ 场景扩散（TTA / 持续 / 联邦 / 半监督）。
- **多模态带来的新问题层**：PMLL 提出的"模态不一致长尾"（单一频率统计量无法反映同一概念跨模态稀缺性差异；共享表示空间纠缠各模态长尾偏差）——与多模态长尾主线直接会合；其共现感知挖掘协议与数据选择方向同族。
- **跨领域可行性证据**：具身智能中影响函数数据选择已完整落地（CUPID 1/3 数据达强性能、ATHENA 313× 加速半数数据匹配全量），说明该技术栈在大模型场景可行。
- **另一重"重加权不好使"证据**：Beyond the Majority（ICRA 2026）实证 re-sampling 对策略学习失效——与重加权象限饱和互证。
- **对"轻量微调万能"的反方证据**：FedPuReL（CVPR 2026，联邦场景）发现微调损害平衡性（见 `01` C3 长尾档）。
