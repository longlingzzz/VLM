# VLM 视觉长尾 × 文本知识：研究讨论交接

> 更新：2026-09-23。依据对话《多模态长尾微调切入点》的完整记录整理；下表中的核心论文另以原论文页面核对。本文是研究状态记录，不是已证实的创新性声明。

## 1. 一分钟接手

**任务目标**：研究下游视觉语言模型（VLM）的视觉长尾微调。关键设定是尾类图片少，但可获得的类别文本知识在数量或语义覆盖度上相对丰富。用户倾向**微调**路线；此前提出文本清洗、视觉属性 coreset、文本教师/视觉学生，但尚未确定模型、任务、数据集或最终方法。

**当前最值得检验的两个问题**：

1. **类别知识到实例监督的失配**：类别级正确的属性，如果当前图片没有可见证据，却被写成“图中可见”的问答或描述，会形成图像条件下的错误训练信号。这种影响是否随着视觉样本减少而放大？
2. **尾类的文本主导**：额外文本知识能否改善尾类视觉识别？过多文本监督是否让生成式 VLM 更依赖类别先验、降低对图片的依赖？

两者都只是**待验证假设**。最小下一步是定下生成式 VLM 的下游任务，建立可人工审计的属性可见性标注，然后做受控实验。暂不把 coreset、LoRA 结构或蒸馏当成已确定创新点。

## 2. 讨论怎样演变

| 阶段 | 曾考虑的思路 | 目前状态 |
|---|---|---|
| 一般 VLM 长尾微调 | 重采样、class-balanced loss、校准、tail LoRA、梯度冲突、跨模态对齐 | 可作基线或诊断；“生成式 LVLM 存在长尾”已有直接研究。 |
| 模态不对称设定 | 尾类视觉样本少，文本知识较完整，用语言补视觉 | 保留为核心场景；**真实数据是否满足这个前提尚未测量**。 |
| 文本清洗 | 从原始文本抽取视觉属性，评估视觉相关性、类别真实性、判别性 | 保留为数据准备；单独作为创新较弱。 |
| 属性 coreset | 用覆盖度和去冗余从大量文本中选小型属性集 | 可用作控制文本预算与语义覆盖的模块；概念选择、属性提示和 coreset 已有邻近工作。 |
| Teacher/Student 蒸馏 | 丰富文本教师指导稀缺视觉学生 | 因用户偏好微调，暂退为可选基线；不能假设一张图呈现类别的全部属性。 |
| 实例感知选择 | 对每张图只使用当前可见的类别属性 | 导向“类别正确、实例无视觉支撑”的问题定义；已有图文失配/数据清洗工作，须进一步收窄。 |
| 噪声 × 视觉稀缺 | 测视觉 shots 与实例无支撑文本比例的交互 | 当前候选 A；同类的 few-shot × noisy label 已研究，需清楚区别噪声定义和训练场景。 |
| 文本主导 × 视觉稀缺 | 测额外文本监督是否降低尾类的视觉依赖 | 当前候选 B；是后来新增的机制假设，不能视为已观察到的现象。 |

## 3. 研究设定与术语

令类别为 $c$、图片为 $x$、属性命题为 $a$、基于图片的问题为 $q$。$N_c^V$ 是该类**独立图片**数量；$K_c^T$ 表示可用文本知识的**语义覆盖度**，比纯文本条数更有意义。研究设定为 $N_{tail}^V \ll N_{head}^V$，而 $K_{tail}^T$ 未必同样低。后一条不能先验保证：要测文本来源、事实质量、属性类别覆盖和重复度。一个可探索的描述量是 $\rho_c=K_c^T/K_c^V$，其中视觉覆盖度 $K_c^V$ 也需要操作化定义。

**类别真实性** $C(c,a)$：属性对类别是否可靠。**实例视觉支持** $S(x,a)$：当前图片能否支持“图中可见属性 $a$”这一断言。$S$ 应由可见证据判断，不等同于模型输出置信度，也不等同于该物体真实具有该属性。此前对话用 $P(a\mid x)$ 作直观简写，后续实验宜改用清晰的标注协议。

以 red-winged blackbird 的红色肩斑为例：类别知识可以正确，但背面、遮挡或低分辨率图片中无法判断肩斑。把“图中可见红色肩斑”作为这张图的答案，会使模型可凭类别先验作答，而不必读图。**知识不在图上可见，本身还不是训练噪声**；只有在任务要求依据图像作答、却把该属性当作图像证据来监督时，才构成这里讨论的 *class-to-instance grounding noise*。若问题明确询问“一般而言该物种具有什么特征”，类别知识仍可能是正确答案。

| 情形 | 类别知识 $C$ | 当前图片视觉支持 $S$ | 处理原则 |
|---|---:|---:|---|
| 稳定且可见 | 高 | 高 | 可用于图像条件监督。 |
| 类别正确、实例无支撑 | 高 | 低或未知 | 关键研究对象；可标为不可见/无法判断，避免强行生成肯定答案。 |
| 偶然可见但非稳定类特征 | 低 | 高 | 可描述该实例，不应当作类别通用知识。 |
| 事实错误且无支撑 | 低 | 低 | 属于一般知识错误或幻觉。 |

标注还应区分 **属性在物体上不存在**、**存在但因遮挡/视角不可见**、**图片可见但模型没识别**；最后一种是模型感知失败，不能直接算作数据标签噪声。另需区分非视觉知识（栖息地等）、正确但低判别力的知识，以及普通错图/错标签。

## 4. 数据与训练形式：为什么不能照搬 CLIP 配对思维

CLIP 常以图文配对与对比学习为教学起点；BLIP 同时结合图文匹配、对比与生成目标。生成式 LLaVA、Qwen-VL 一类模型的下游指令微调则更应按 **image + instruction → response** 理解：同一图片可构造多个问题、描述或对话，训练通常主要优化目标回答的 token。具体数据模板、视觉 token 处理和 loss mask 必须以所选模型实现为准。[LLaVA 原论文](https://arxiv.org/abs/2304.08485)

例如同一张鸟图可以有“是什么鸟？”以及“肩部斑块是什么颜色？”两条样本。第二条若肩部不可见，即使类别知识正确，也不宜监督一个确定的可见颜色。构造数据时应逐条记录：**图片、问题、回答、知识来源、类别真实性、实例可见性、是否要求只看图、损失作用位置**。同图多问答不能算多张独立视觉样本；训练/测试需按原图及近重复图分组，防止泄漏。

## 6. 目前能说、不能说的结论

**可说**：图文失配、属性幻觉、视觉指令数据清洗、VLM 长尾、文本语义增强尾类和 few-shot noisy label 均已有研究。已有工作尚未让本对话的两条候选问题自动失效，但也没有证明它们新颖。当前可以谨慎表述为：*在已检查的论文范围内，尚未确认有工作完整研究“视觉样本稀缺、类别知识正确但实例无视觉支撑的文本被用作生成式 VLM 监督”及其随视觉频率变化的效应；需继续系统检索和实证验证。*

**不能说**：“text-image 还没人做”“属性级噪声没人做”“shots × noise 就是创新”“尾类文本一定充足”“尾类噪声必然被放大”“加更多文本必然提升或损害尾类”。对话中关于 tail 视觉表示、gradient conflict、text dominance 的因果解释都属于假说。先前把 HalluciDoctor 概括为“文本本身错误”也过窄；它确实处理图像与视觉指令不一致的属性等内容。

## 7. 待解决问题与可执行下一步

1. **固定任务和模型**：优先选一个可复现的生成式 VLM 指令微调任务（如细粒度视觉问答/属性问答），再定具体模型与预算；保留 CLIP prompt learning 作为邻近基线而非混成同一训练机制。阅读训练配置时核对 image、instruction、response 和 loss mask。
2. **验证设定存在**：选择一个真实细粒度或长尾视觉数据集，统计每类独立图片量、可获取文本的事实正确率、非重复视觉属性覆盖、图片对这些属性的可见覆盖；报告 head/medium/tail 的分布。若文本覆盖也同样长尾，应修改课题设定。
3. **建立小型审计集**：从类别属性出发，人工给图片-属性对标注“可见支持 / 明确不成立 / 由于遮挡等无法判断”，并记录问题是否要求图像证据。抽样复核标注一致性；不要直接把 VLM 自己的置信度当真值。
4. **先做候选 A 的受控实验**：固定类别、候选图片池、评测集、总训练 token、每图问答数、训练步数和文本覆盖；独立改变视觉 shots（如 100/50/10/5/1）与**类别正确但实例无支撑**的监督比例（如 0/10/20/30/50%）。记录少图条件下的重复采样量，避免把重复训练效应误认作噪声效应。先小规模验证流程，再扩成完整矩阵。与普通错标签、事实错误文本和随机去噪作区分；按类/原图独立评估，报告 tail/head 准确率、不可见属性的肯定回答率及交互效应与不确定区间。
5. **检验候选 B**：在相同图片和文本预算下改变类别知识注入强度，对比 image+question、去图 question、冲突属性 question 的回答变化；关注真实视觉证据题的性能。文本依赖须用干预测量，不能只凭 attention 数值推断。
6. **有现象再做方法**：若 A 成立，可比较不筛选、类别级清洗、实例级筛选、不可见时回答“无法判断”、置信加权微调；若 B 成立，再考虑限制类别先验或增加视觉监督。coreset/文本教师仅在证明额外收益且与 MDPR 等清楚区分时加入。
7. **持续查重**：围绕“class-correct instance-unsupported”“visual scarcity × grounding noise”“long-tail modality dominance”“knowledge-to-instance assignment”检索，优先精读上表中 HalluciDoctor、Light Up the Shadows、MDPR、Finer/FINER、LLaVA Steering，并核对它们的实验单位与噪声注入位置。

## 8. 给下一位研究者的直接任务

请先交付一页**实验决策单**：确定下游任务、1 个模型、1 个有类频率信息的数据集、属性标注协议、最小可运行对照、计算预算与停止条件。同时补一张系统文献矩阵，特别核查相关工作是否已经处理“类别事实正确，但图像条件下无法验证”的 SFT 标签。只有在设定、邻近工作和小实验都站住后，才决定主论文方向是 A（grounding noise 的尾类交互）、B（文本主导的尾类交互），还是放弃这两条假设。
