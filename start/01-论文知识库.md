## 第一部分：领域知识地图（跨论文的综合理解）

### 1.1 长尾识别五代方法演进

| 代 | 代表方法 | 核心思路 |
|---|---|---|
| ① 损失代 | LDAM（margin ∝ n^(-1/4)）+ DRW 延迟重加权；Focal、CB 重加权 | 在 loss / 采样权重上纠偏 |
| ② 结构代 | Decoupling（cRT / LWS 表征-分类器解耦）；BBN 双分支累积学习 | 把"学表征"和"学分类器"拆开处理 |
| ③ 收尾与结构代 | Logit Adjustment（log(π_y)，Fisher 一致）；MiSLAS（校准 + BN 重估）；RIDE 多专家 | 调整分数位置 / 多专家容量 |
| ④ 知识注入代 | PaCo（可学习类中心）、BCL（平衡对比）、NCL（CLIP 文本语义环，LIFT 的 SAI 最近祖先） | 给尾部类注入外部语义 |
| ⑤ FM 微调代 | LPT（类平衡 prompt）、VL-LTR（双塔，149M 参数）、LIFT | 换更强的预训练底座 + 轻量微调 |

三个结构观察（来自对 LIFT 引用的 17 个方法的梳理）：

1. **纠偏位置持续上移**：从 loss 标量 → 采样策略 → 模型结构 → 预训练底座本身。
2. **"tail 缺什么"的答案在升级**：缺梯度 → 缺语义锚点 → 缺好底座。
3. **重加权象限已饱和**：2019–2022 年增益从 +3% 收窄到 +0.5%；LIFT 的 SLF 单步带来 tail +19.9 个百分点，是"换底座 > 调权重"的直接证据。

### 1.3 基础模型侧的已有理解（结论级）

- **CLIP**：双塔图文对比结构；InfoNCE 的温度、batch 内负样本、对称 cross-entropy；vendored OpenAI CLIP 源码级阅读（`LIFT/clip/model.py`，含 BPE tokenizer）。
- **Transformer / ViT**：完整数据流——token embedding + 位置嵌入、多头自注意力（显式 Q/K/V）、pre-LayerNorm 残差块、4× MLP 扩展 + GELU。
- **MLLM**：视觉编码器（常用 CLIP ViT）+ 投影层 + LLM 的结构，与判别式 CLIP 的区别已知。
- 评测协议：zero-shot / linear probe / fine-tune 三种口径的区别；长尾指标 Many/Medium/Few = Liu 2019 口径（head > 100、medium 20–100、few < 20 张训练图）。
- 预训练侧长尾专用口径：P-Many / P-Med / P-Few（ICML 2025 论文设立，按**预训练类先验**而非下游训练频次划分）——做"预训练分布长尾"研究时与 Liu 2019 下游口径配合使用。

### A 区：长尾 × 基础模型主线

#### A1. LIFT（ICML 2024）——本研究骨架

- **出处与定位**：*Long-Tail Learning with Foundation Model: Heavy Fine-Tuning Hurts*，ICML 2024；长尾 × 基础模型轻量微调的代表作；官方代码在本地 `LIFT/`（含 vendored CLIP 与 17 个复现脚本）。
- **解决什么问题**：传统长尾方法默认 backbone 可全量训练；CLIP 这类基础模型下，重度微调会损害预训练先验（标题论点 "heavy fine-tuning hurts"），且旧的纠偏组件收益有限。
- **方法**：冻结 CLIP + cosine classifier（文本特征初始化）+ 四组件：
  1. **SLF**：单层轻量微调（只放开最后的 block，搭配 AdaptFormer 等 tuner）；
  2. **LA**：logit adjustment loss（LIFT 所用损失的直接来源是 ICLR 2021 Logit Adjustment）;
  3. **SAI**：用文本语义弥补视觉样本缺失，专攻 tail；
  4. **TTE**：test-time ensemble（five-crop），推理期免费增益。
- **关键数字**（ImageNet-LT 消融，逐加组件）：Overall 60.9 → +SLF 68.9 → +LA 74.9 → +SAI 77.0 → +TTE 78.3；Tail 13.8 → 33.7 → 61.7 → 71.5 → 73.4。即 SLF 单步 tail +19.9；LA 是最大单步（Tail +28.0、Head −5.0——重分配而非普涨，佐证"LA 是分数位置调整不是 class weight"）。
- **其他基准**（ViT-B/16，含 TTE）：ImageNet-LT 78.3（Many/Med/Few = 81.3 / 77.4 / 73.4）；CIFAR-100-LT β=100 81.7；Places-LT 52.2；iNat 2018 80.4（20 epochs，对比 LPT 160 epochs 的 76.1）。
- **tuner 可替换性**（原文表 6）：BitFit 77.0 / VPT-shallow 75.2 / VPT-deep 77.2 / Adapter 78.1 / LoRA 76.9 / AdaptFormer 78.3（ImageNet-LT 整体）——任意 PEFT tuner + 框架组件即大胜传统路线，框架价值大于 tuner 选择，tuner 之间差异小。
- **与本研究的关系**：已完整复现的 baseline（见 `03`）；"不碰数据"路线的代表——**"数据选择 × LIFT 骨架"在文献中接近空白**。

#### A2. Rethinking the Bias of Foundation Model under Long-tailed Distribution（ICML 2025）——与本研究在问题层会合

- **出处与定位**：ICML 2025；LIFT 的教科书式延续——继承全部下游组件，补上"预训练分布长尾"这个盲点。
- **解决什么问题**：预训练数据本身不平衡，基础模型把这一偏差继承为**参数不平衡**；下游微调时的 re-balancing 修不掉它——作者验证过把预训练先验校正放进训练损失（无效），同样的校正只放在微调后的 logit 上才有效（KNN 分析显示收益只在分类器）。
- **方法**：因果图建模——不完整语义因子 C 是混杂变量，backdoor 路径 X←C→Y；用 backdoor adjustment 估计 P(Y|do(x)) = Σ_c P(Y|b,c)·P(c)，取 P(c) = 1/M 均匀，b 由 LA 产生（**LA 从独立组件降级为内部组件**）；M = 3 个基础模型（CLIP / OpenCLIP / MetaCLIP）各自带 LA 微调后**等权融合 logits**。
- **关键数字**：ImageNet-LT 79.57 vs LIFT 77.0（+2.57，few +3.49）；Places-LT 53.01；iNat 82.01；预训练不平衡因子 IF（Places365-LT 上）CLIP 57.50 / OpenCLIP 63.25 / MetaCLIP 60.20；代价 717 GFLOPs（单模型的 3 倍）。
- **与本研究的关系**：核心学术判断的对象（见 `02` 第 4 节——数据选择可能成为参数不平衡的"第三修正通道"）；其"预训练分布长尾"论点与数据选择兴趣在问题层会合。
- **备注**：无方法缩写名；**无官方代码**（arXiv / OpenReview / PMLR 均无仓库链接；复现需自组：AdaptFormer、LA、三个预训练权重都开源）；3× FLOPs 是效率对比锚点——LIFT 轻量哲学与集成哲学在成本轴上对立。

#### A3. LIFT+（TPAMI 2025）

同组官方续作：一致性类条件轻量微调，训练从 100 epochs 收敛到 ≤15 epochs，继承 SAI / TTE；官方代码 `shijxcs/LIFT-plus`。延续工作阅读首选。

#### A4. Sage / SG-Adapter（IJCV 2026，arXiv 2507.12807）

LIFT 骨架上的语义升级：类描述语义调制逐 block 特征 + 分布失配补偿因子 + FIT 插值。ImageNet-LT 78.8 / Places-LT 52.7 / iNat 80.9，few +0.9~2.9；代价 8.19M 参数（LIFT 为 0.62M）。

#### A5. LT-Soups（NeurIPS 2025）

两阶段 model soup；发现单一 PEFT 方法在头部/尾部比例不同的数据集上各有强弱——**微调策略本身成为研究对象**的证据（无单一 PEFT 通吃）。

#### A6. How Does Fine-Tuned Foundation Model Help for Long-Tailed Learning（ICLR 2026 投稿，LAMDA）

协议元研究：论证微调后 CLIP 的先验偏差已减小，**LA 在 FM 时代需要重新审视**——LIFT 组件理论反思的代表。

#### A7. Neglected Tails in Vision-Language Models（CVPR 2025）

长尾存在于 CLIP 预训练数据本身，与下游长尾叠加——"长尾定位从下游数据前移到预训练分布"的代表工作。

#### A8. PMLL：模态不一致长尾（出处未知，摘要级记录，2026-09-20）

- **定位**：多模态长尾的**问题定义层**新分支，与本研究主线（多模态长尾）直接会合。
- **问题定义**：视觉-语言生成模型在 object hallucination（对象幻觉）与 rare concept understanding 上系统性失败；现有长尾方法用单一频率统计量定义长尾，无法反映**同一概念跨模态稀缺性差异**（文本频繁但视觉 grounding 薄弱）；共享多模态表示空间把各模态长尾偏差纠缠在一起。
- **五个组件**（摘要级）：模态解耦重加权（建模模态间稀缺性差异）、稀有词强化（改善稀有 token 表达）、自适应任务感知优化（平衡多任务贡献）、关键词解耦长尾评估指标、共现感知长尾挖掘协议（减少共现导致的估计偏差）。
- **备注**：题名、作者、出处未知，摘要无任何数字；以下细节待原文确认——频率统计的计数单位、visual grounding 的度量方式、解耦与 reweighting 公式、共现偏差控制方法、多任务定义、组件组合与消融。完整记录在 CVLearning `docs/learning/research/pmll-modality-inconsistent-long-tail.md`。

### B 区：数据选择 / coreset 谱系（与"选择数据让长尾收敛更快"直接相关）

#### B1. CHIPS（CVPR 2026）

- **解决什么问题**：继续预训练（continued pre-training）的数据选择——从大规模数据中选子集，使目标域性能好且保留通用能力（retention）；实验场景为 17 个医学基准。
- **方法**：一步更新（one-step）影响函数近似 + 曲率代理：打分形式 gᵀM⁻¹u（M 为端点子空间上的曲率代理矩阵，配合随机投影降维）——**数据选择打分中唯一的轻量曲率用法**。
- **谱系定位**：CHIPS = CRAIG 的计算结构 + 度量从单位矩阵升级为端点子空间 M⁻¹ + 预算/保留工程项；其 Dot 基线是该模板的退化版。**没有长尾结构**。
- **与本研究的关系**：机会格"曲率-影响打分 × 显式长尾处理"的现成打分器（见 `02` 第 3 节）。

#### B2. CRAIG（ICML 2020）

梯度子模覆盖：facility location 结构 F(S) = L({s₀}) − L(S∪{s₀})，贪心有 (1−1/e) 近似保证；covtype 10% 子集 2.75–4.5× 加速。谱系核心——保整条 SGD 轨迹（与影响函数"固定参数点的局部量"是分叉点）。

#### B3. NUCS（2025）

EL2N 难度 + 类级预算（proportional 为底线、按类难度上浮更好）+ 类内难度窗。CIFAR-100-LT 90% 剪枝 +5.6；iNat21-mini 80% 剪枝 +15.2；2× 提速。**类预算带来大头收益，但打分无影响函数**；同时是"难度型分数系统性欠选少数类"的证据来源。

#### B4. RCAP（UAI 2025）

动态 per-class 预算闭式解、每 epoch 自适应——NUCS 的动态化 + 闭式化；动机明确（"现有动态剪枝丢 minority"），但打分仍是类内 loss。**最接近机会格的竞品**。

#### B5. CSOR（ICML 2026）与公平性线

CSOR：re-ID 场景，类预算从超参数升级为联合优化输出——第一篇把类平衡写进 coreset 目标函数的主会论文。ECS（CIKM 2025）：公平性视角自适应剪枝。FairCore（ICML 页面出现，per-group ε/δ 双近似保证，**待确认**）。

#### B6. Dharmasari 副作用审计（NeurIPS 2025）

审计发现：现有 coreset 方法制造子集类不平衡、伤 worst-group——**审计了问题但没有给判据**。机会格的第四个邻居。

#### B10. 与"收敛更快"同族的省训练成本邻居

效率大头在预训练 + 轻量适配这一代（LIFT / LPT）；省 epoch 的已有手段：**LORT**（二阶段收敛监测，判断何时停止训练）、**Decoupled Optimisation**（成本减半）。它们与数据选择同属"省训练预算"族，是"选择数据让长尾任务收敛更快"的对照方法。

#### B11. coreset 建议阅读顺序（衔接已有影响函数基础）

CRAIG（第 3–4 节，与影响函数 I_up 并排对照）→ 用 F(S) 验证一次子模不等式 → Forgetting → GraNd / EL2N → Cartography → Moderate → 几何线（Herding / K-Center）快过 → NUCS → Class-Proportional → SIMILAR → 回读 CHIPS（此时 CHIPS = 影响函数的子空间化 + 预算工程化）→ Moser survey（arXiv 2505.17799）补全景。

### C 区：多模态 / VLM 基础与前沿

#### C1. BLIP：Bootstrapping Language-Image Pre-training（ICML 2022）——图文理解 + 生成统一架构

- **出处与定位**：ICML 2022（PMLR 162: 12888–12900），Salesforce，官方代码开源；视觉-语言预训练中"理解 + 生成统一"路线的代表（BLIP-2 为其延续）。本地精读笔记：`docs/papers/foundation-models/2022-BLIP.md`。
- **解决什么问题**：CLIP 双塔高效但两个模态大部分时间互不交互、没有逐词生成目标；早期视觉-语言预训练模型或只擅长理解类任务、或只擅长生成类任务；大规模网页 alt-text 噪声大（网站名、相机信息等无关文本），高质量人工 caption 成本高。
- **方法**：
  1. **MED 架构**（Multimodal Mixture of Encoder-Decoder，多模态编码器-解码器混合）：共享大部分文本 Transformer 参数，三种工作模式——unimodal encoder（文本双向 self-attention）、image-grounded text encoder（文本块加 cross-attention 读取图像 token）、image-grounded text decoder（causal self-attention + cross-attention，支持从左到右逐词生成）；
  2. **三个预训练目标**：**ITC**（图文对比，继承 CLIP 式对齐，建立粗粒度共享空间）、**ITM**（图文匹配二分类，优先采样相似但不匹配的 hard negatives，迫使 cross-attention 学细粒度对应）、**LM**（根据图像逐词生成 caption，L_LM = −Σ_t log P(w_t | w_{<t}, I)）；
  3. **CapFilt 数据自举**：从预训练 MED 派生两个模块——Captioner（用 LM 为网页图片生成合成 caption）与 Filter（用 ITC/ITM 判断原始文本与合成文本是否与图片匹配，删除噪声配对）；过滤后的原始文本、合成文本与人工标注文本合并成新数据集，再从头预训练新的 BLIP。"bootstrapping"指用已有模型改善下一轮训练数据，不是统计学的 bootstrap sampling。
- **与本研究的关系**（两层）：
  1. PMLL 关注生成式 VLM 的对象幻觉与稀有概念理解——BLIP 的 ITC/ITM/LM 三目标 + MED 是这一族模型的基础架构，读 PMLL 方法部分前需要它；
  2. **CapFilt 是 VLM 预训练中"用模型能力做数据侧操作"的先例**（生成合成 caption + 过滤噪声配对）——与数据选择方向同族；CVPR 2026 相邻工作 DBG（生成补 tail）是同一思路在长尾场景的对应物。
- **备注**：本地笔记未录实验数字，引用数字以原文为准。与 LIFT 的区别：BLIP 重新做视觉-语言预训练（数据清洗 + 三目标统一训练），LIFT 在现成 CLIP 上做长尾分类的轻量微调。
