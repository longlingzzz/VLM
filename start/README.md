## 一页速览（2026-09-21 历史状态；新灵感见 04）

- **研究者画像**：C++ 基础扎实的机器学习研究者，Python/PyTorch 已达到能独立复现 ICML 论文并设计 18 组对照实验的水平；具备单卡远程 GPU 训练的完整工程体系；习惯用多子代理交叉验证的方式做文献调研。
- **研究定位**：核心兴趣是"选择数据让长尾任务收敛更快"；方向主线为**多模态长尾**（图文预训练分布、VLM/MLLM 长尾适配、多模态 prompt 与跨模态表示）。
- **三块核心资产**：
  1. 围绕 LIFT 展开的长尾 × 基础模型论文知识库（`01`）；
  2. 九轮调研沉淀的研究机会地图与空档确认——"曲率-影响打分 + 显式长尾处理"交叉格在已核实文献中无人占据（`02`）;
  3. LIFT 完整复现（80.0% vs 论文 80.3%）+ 18 组方法学对比的实验产出与训练代码（`03`）。
