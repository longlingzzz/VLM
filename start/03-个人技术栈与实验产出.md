## 2. 计算环境与远程训练体系

- **双机环境**：
  - MacBook（`~/CVLearning`）：代码、Git、学习资料与最终实验结果的**唯一主副本**；MPS 后端可跑 zero-shot 与小规模实验（已有 zero-shot RN50、SSF RN50 1 epoch 记录）。

- **自建 `remote` 训练体系**（252 行 bash，Mac 端客户端 / WSL 端 worker 同一脚本）：
  - `sync`：rsync 白名单同步（仅 `LIFT/` 与脚本本身，排除数据/权重/venv），不用 `--delete` 保护远端数据；
  - `train`：验收链 = SSH 连通 → 远端项目存在 → `.venv/bin/python` 存在 → flock 可用 → `torch.cuda.is_available()` 断言 → 同步 → 生成 run_id（时间戳 + 随机 hex）→ `flock -n` 单实例锁（防 GPU 争用）→ `nohup` 后台启动（断网不停）；
  - `status`：区分运行中 / 已完成 / 失败（退出码）/ 已停止，输出完整参数与日志尾部；
  - `fetch`：幂等拉回 `LIFT/output/<run_id>/` 到本地 `results/remote/<run_id>/`，远端副本保留；
  - 配套 stub 假 ssh/rsync 的 bash 单元测试（`tests/remote_test.sh`）。
- **网络**：Tailscale 组网 Mac ↔ WSL（国内 Peer Relay 优先）；依赖 / 权重 / 数据集优先中国大陆镜像（实测上海交大镜像），下载后校验完整性。
- **数据集经验**：CIFAR-100-LT（ir10 / 50 / 100，本地已备 `data/`）、ImageNet-LT（zero-shot 已完成）、Places-LT / iNaturalist2018 配置可用。

## 3. 已完成实验产出（数字为准）

### 3.1 LIFT 复现（CIFAR-100-LT IR100）

设置：CLIP ViT-B/16 冻结 + AdaptFormer（论文默认配置）、论文协议 10 epochs、logit adjustment loss、cosine classifier（文本特征初始化）、micro batch 32、seed 0。

| 指标 | 论文 | 复现 |
|---|---:|---:|
| accuracy | 80.3% | **80.0%** |
| TTE 增益 | +1.4 | +1.3（30 epochs checkpoint 上 80.9 → 82.2） |

相差 0.3 个百分点，基本复现；TTE 增益量级与论文一致（验证了论文 Table 4）。

### 3.2 方法学对比（18 组：微调方法 × 训练轮数）

固定数据 / backbone / seed / batch，只变微调方法（Baseline 只训分类头、Adapter、AdaptFormer、LoRA、SSF、VPT 三种插入位置）与轮数（3 / 10 / 20 epochs）。20 epochs 主结果：

| 方法 | accuracy | many−few 差距 | worst-case |
|---|---:|---:|---:|
| **AdaptFormer** | **80.9%**（全面第一：accuracy / macro-F1 / few / hmean / gmean） | 8.2pp | 37% |
| Adapter | 80.5% | 8.4pp | 27% |
| SSF | 79.9% | 10.3pp | 33% |
| LoRA | 79.7% | 8.7pp | 33% |
| VPT（全程） | 79.4% | 7.5pp | 32% |
| VPT（前五层） | 78.5% | 7.9pp | 26% |
| VPT（后五层） | 76.1% | 6.9pp | 28% |
| Baseline（只训分类头） | 68.5% | 22.5pp | 3% |

四条主要观察：

1. 所有 PEFT 显著优于只训分类头（76.1~80.9% vs 68.5%）——支持"轻量微调"主张；
2. PEFT 的优势不只在总精度，更在尾部类：many−few 差距从 22.5 个百分点压到 6.9~10.3；
3. **VPT 插入位置在 CLIP 底座上的新数据点**：全程 > 前五层 > 后五层（79.4 / 78.5 / 76.1）——补充了原始 VPT（监督 ViT：浅层重要）与 Improving VPT（自监督 ViT：深层反而好）之外的第三种底座规律；
4. 训练轮数边际收益递减但最差类别持续改善：AdaptFormer 10→20 epochs 总精度只 +0.9，worst-case 从 25% 升到 37%。

### 3.3 自发探索：VPT-deep + Adapter 朴素组合

20 epochs 下组合 80.4%，未超过 AdaptFormer（80.9%）与 Adapter（80.5%）单独使用——"1 + 1 < 最好的那个 1"，且该关系在 3 / 10 / 20 epochs 下一致。归因：双 tuner 可训练参数明显增多导致过拟合，与 CoPrompt 报告的"朴素联合引入过拟合"一致（文献中有效组合需要额外一致性约束或门控）。属初步观察，未做参数量对齐的严格控制。

### 3.4 ImageNet-LT 进展（2026-09-19 时点）

zero-shot 已完成：accuracy 66.8%（50,000 张，many / med / few = 67.8 / 66.3 / 65.9%）；AdaptFormer 训练（10 epochs，micro batch 64）汇报时点在排队 / 进行中。

### 3.5 可复用数据资产

全部实验的 100 类逐类准确率（class accuracy）已保存为 json（LIFT 代码自动保存 + 代理脚本统计），可做单类行为分析；原始记录在 CVLearning `docs/experiments/` 与 `results/remote/`。

## 5. 协作偏好（新项目可直接继承的约定）

以下是从 CVLearning 协作中固化下来的偏好，新项目的代理或协作者直接继承可省去磨合：

- **语言与术语**：项目文档与讨论默认中文；必要英文术语保留原文，并在首次出现时附中文解释。
- **不用比喻性语言**（地形、上坡/下坡、碗、旋钮等）；类比仅在明确要求时使用，且与公式、shape、代码等真实计算分开写。
- **表述完整、不缩略**：语义关键的短语完整写出，不使用未定义的简称。
- **多变体 / 多结果默认并列呈现**（表格或并列代码块）；公式用 Unicode 记号（环境不渲染 LaTeX）。
- **偏好高密度、有逻辑条理的详细输出**，不精简。
- **证据纪律**：分级标注【已核实】/【搜索级】；勘误向上追溯；数字、出处、实验设置未知时不虚构，标注"待原文确认"。
