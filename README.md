# VLM × 多模态长尾研究

本项目承接 CVLearning 的研究积累，围绕视觉语言模型（Vision-Language Model，VLM）与多模态长尾问题开展研究。当前研究灵感**以 PMLL 的“模态不一致长尾”问题为出发点**：类别的标志性判别特征已经体现在文本中，但尾类现有的极少数图片可能完全没有展示这些特征，形成文本与视觉训练样本之间的判别证据覆盖缺口。这个缺口何时构成图像条件下的错误监督、怎样影响微调，均待进一步界定和检验。已核对用户提供的 PMLL 原文：它处理跨模态概念稀缺，也增强稀有属性词；当前问题进一步聚焦属性在具体尾类图片中的可见支持。数据选择与降低长尾训练总成本是此前的研究兴趣，继续保留为候选路线。

## 研究定位

- 主线：图文预训练分布、VLM / 多模态大语言模型的长尾适配、多模态提示与跨模态表示。
- 当前优先切入点：以 PMLL 提出的跨模态稀缺性差异为问题起点，厘清文本已包含标志性判别特征、尾类少量图片却未展示它的证据覆盖缺口；区分“图片未提供证据”“训练回答无证据”“图片明确反证”三种状态。文本主导是后续机制假设；文本清洗、属性选择和蒸馏均未定为最终方法。
- 既有候选路线：以 LIFT 为实验基础，研究类间预算、类内样本选择与预训练先验之间的关系；影响函数和曲率近似是候选工具。
- 核心反方假设：删去冗余样本无法补足尾部缺失的信息；选择成本可能抵消训练节省；便宜的模型侧方法可能已经足够有效。
- 延伸问题：面向预训练弱类的数据选择，是否有助于改善单模型的长尾表现？交接材料中的多模型对照叙事需重新核对原文与实验协议。
