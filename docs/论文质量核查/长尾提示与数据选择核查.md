# 四篇附件论文独立评估（2026-09-23）

范围：`papers/LAMP.pdf`（26 页）、`papers/NUCS.pdf`（13 页）、`papers/RCAP.pdf`（15 页）、`papers/priority/MDPR-FindingsEMNLP2025.pdf`（14 页）。页码均为 PDF 物理页；书面论文的印刷页码不同。四份均含正文、实验、参考文献和附录，没有因附件缺页而判为“信息不足”。以下为论文报告结果及本次核查，不是独立复现。发表、团队与引用用外部原始来源核对；没有查到可信完整引文索引时不臆造引用数或引用者。

## 1. MDPR：值得读（对当前“文本知识 × 长尾 VLM”最直接，但证据缺口未处理）

**论文**：*LLM-empowered Dynamic Prompt Routing for Vision-Language Models Tuning under Long-Tailed Distributions*。PDF p1、ACL Anthology 官方条目 https://aclanthology.org/2025.findings-emnlp.799/ 均确认为 Findings of EMNLP 2025。建议当前项目阅读次序：MDPR → LAMP → NUCS → RCAP。等级“值得读”；若专门做类别文本先验与长尾识别的竞品图，可提升为必读竞品，但不能把它当成逐图属性证据工作的直接证明。

1. **问题价值**：下游长尾微调真实存在偏头部问题，作者在 CIFAR-100-LT、ImageNet-LT、Places-LT 三个公开基准中报告 Many/Medium/Few（p6 表1，p7 表2，p8 表3），并非自造问题。对本项目的直接价值是“类名生成类别知识用于尾类分类”的现成强基线。其工作是判别式 CLIP 分类，不是生成式 VLM 图像条件指令微调，未测类别属性是否被每张尾类图像可见支持（§3.2 p4-5）。
2. **原创性**：五类知识（一般外观、细粒度外观、功能、环境、易混类差异）由 LLM 离线生成，冻结 CLIP 编码后，逐图对每一类的五种提示做多头注意力路由，外加先验对齐、知识对齐和与原分类 logits 融合（§3.2–3.5，p4-6）。组合与类条件路由是具体增量；属性提示、CLIP 语义对齐、logit adjustment、注意力、蒸馏分别已有先例，非全新原理。**关键缺口**：p3 Eq(2) 假设预训练类别频率 `Npre_c` 以 `α log Npre_c` 加到 logit，但未测实际 `Npre_c` 或操纵预训练分布；“消除预训练偏差”只能视为机制假设，不能由下游准确率直接推出。
3. **实验扎实度**：三公开长尾集、CoOp/MaPLe 两宿主、含 Candle、CPRL、TextRefiner 等基线，较好；p7 表2 CIFAR-100-LT IR100 MaPLe Few 58.43→67.17，但 Candle 的 Few **67.93，仍高于 MDPR-MaPLe**；p8 表3 Places-LT MaPLe Few 28.73→50.99，ImageNet-LT 60.37→70.04，收益有实质性。消融 p8 图3 加语义+正则、p9 表5 删除五维提示，但没有“相同五维提示静态平均/固定权重 vs 动态路由”的同成本对照，也未分拆 C-MHA、先验对齐、知识对齐、logit 融合各自贡献；机制归因弱于整体收益。p7-8 没有多随机种子标准差或置信区间。p8 表4 补 RN50/RN101 Places-LT，仅一个数据集，表中零样本行仍写 `CLIP-ViT-B/16`，标签存疑。
4. **可复现性**：论文给代码链接 https://github.com/Sha843/MDPR ，仓库公开，页面目前顶层只有 `MDPR with Maple` 与 README，故 CoOp 全流程代码是否在内需进一步核查（https://github.com/Sha843/MDPR）。p6、p11-12 附录 A 给优化器、训练轮数、学习率、损失权重网格和典型取值；p12-14 附录 B 有提示模板与离线成本。但 Qwen2.5 未具体指定大小、版本、API 配置，数据验证划分与每个数据集最终权重未全部固定列明；p14 所谓文本核验仅格式/关键词检查，无人工事实准确率或逐图视觉可见性检查。原则上可尝试复现，但知识库质量及配置不能仅靠论文完全核验。
5. **结论可信度**：整体分类提升有表格支持；“预训练长尾偏差得到缓解”无预训练频率观测或因果干预，存疑。p9 结论称“open-world long-tailed recognition”，但 §4 全是预定义闭集分类，属于超范围表述。p9 表6 训练每轮 CoOp 1115→1229s，MaPLe 1361→1375s；p14 附录 B.2.3 1000 类知识库生成约 3900 秒，并未纳入每轮时间表，因此“轻开销”要按一次离线成本、训练成本、推理成本分别说。p9 表5 `All` 行 Few=48.24 与 p8 表3 CoOp+MDPR Places Few=47.96 略不同，需代码或种子解释。
6. **发表痕迹**：Findings EMNLP 2025 官网可核；通讯作者 Xiangxian Li 等此前有同主题 *Cross-modal learning using privileged information for long-tailed image classification*（2024，出版社 https://www.sciopen.com/article/10.1007/s41095-023-0382-0），有一定持续产出。准确总被引和“谁引用”未找到可复核完整来源，**信息不足：需公开引文索引与可确认引用正文**；不能把低检索量作质量证据。
7. **写作迹象**：p1-2 引联邦学习相关工作作为引言铺垫，与本文主机制联系弱；p4 声称五维“互补”有删维消融支持，但 p9 表5 删 Functionality 对 Few 48.24→47.48，仅 0.76 个点，称每维“indispensable”偏满。p13 表7 用 Qwen2.5/LLaMa4/DeepSeek-V3 的 CLIP 相似度均值 0.8371/0.8360/0.8354 选 LLM，未给尾类准确率或属性事实核验；这是“以易算代理量包装知识质量”的具体水法。没有证据称自引比例异常；避免泛化成“整篇水论文”。

**阅读节段**：先 p4-6 §3.2–3.5，拿到五维知识库和逐图路由计算；再 p7-9 表2-6，比对尾类结果、消融和成本；最后 p12-14 附录 A/B，核对提示构造与复现缺口。

## 2. LAMP：值得读（实验较广，机制组合增量，尾类机制证据有限）

**论文**：*LAMP: Long-Tailed Multi-modal Prompt Tuning for Vision-Language Models*。PDF p1、Springer 官方 https://link.springer.com/article/10.1007/s11263-026-03013-9 核实 IJCV 2026，2026-09-17 在线发表。当前日期离发表仅数日，被引量不宜评价。

1. **问题价值**：冻结 CLIP 的长尾 prompt tuning 和基类到新类泛化是实际问题。论文构造 11 数据集长尾 B2N，含不同 IR、少样本、跨数据集、域泛化（p6-7 §4.1），适合做长尾 CLIP 微调参考。但与当前“尾类图片不展示类别文本属性”问题不同：没有属性级文字知识/图片可见支持标注，也无生成式指令微调。
2. **原创性**：按当前图像 CLS 从跨模态 prompt pool 取 K 个成对视觉/文本提示，加共享提示，再用外部 bias 逐步均衡 prompt 激活（p4-6 §3.2、Algorithm 1）；组件借自 prompt pool、MaPLe/跨模态共享与 MoE 负载均衡，组合在长尾 CLIP 上有工程新意，原理原创性中等。p16 的单层 toy theorem 论的是动态提示可表达性，不能证明真实尾类机制。
3. **实验扎实度**：比 CoOp、CoCoOp、MaPLe、TCP、MMA 及长尾 Candle；平衡方法加 Logit Adjustment，协议在 p7 说明。11 数据集、IR10/20/50、5 seeds，另 IR100/200 和 1/2/4/8-shot；跨数据集/域泛化 p12 表5/6，组件 p15 表10。例如 IR10 B2N 平均 HM-A：MaPLe+LA 78.56、Candle 78.02、LAMP 不校准 80.00、校准 80.93（p8 表2）；组件 ImageNet HM-A：CLIP 68.05、MPP 70.05、MSP 70.94、三者合 72.96（p15 表10）。这些支持整体有效，不是只在自家数据集上赢。限制：多数主结果是 base/new 谐均与 macro-F1，没有 Many/Medium/Few 或逐尾类表现，不能充分证实“尾类获益”分布；p20 表18 EuroSAT IR50 的校准 HM-A 83.28±24.75、HM-M 74.10±16.66，方差极大。p6 明确“带校准”额外用**新类未标注训练图像**更新 LBO bias；表2/3已单列“不校准”，比较时必须用同为归纳式的行。
4. **可复现性**：p23 附录 F 给超参表、代码/训练脚本/配置/检查点 https://github.com/xuc865/lamp ，官方 Springer 也链接同仓库。p7 写主实验 K=6、S=4、prompt dimension=64；p23 表25 对 base-to-new imbalance 却列 `share_dim=32`、`share_token_num=2`、`extra_token_num=2`；这些配置字段与文中 K/S/D 的映射不清，复现时应以代码对应的实际实验配置核对，**存疑**，但不能在未查代码前断言错误。数据公开。
5. **结论可信度**：多数平均提升及宽基准成立；p12 “一致泛化”跨数据集源端 ImageNet 72.70 与目标平均 67.44（p12 表5）有支持。不过“非偏预测/防止头类过拟合”主要从 HM、macro-F1 与 t-SNE 推断，缺负载按头尾分布及尾类独立图像覆盖的量化，机理表述较强。p13 表7 效率 LAMP 1.6s/batch，比 MaPLe 2.0 快但比 CoOp 0.5 慢；不能泛称比所有 prompt tuning 更高效。p20 大方差处不可称“所有数据都稳定”。
6. **发表痕迹**：官方 IJCV 页面确认为 2026-09-17；同一第一作者/团队另有 ICLR 2026 *Long-tailed Test-Time Adaptation for Vision-Language Models*（OpenReview 官方 https://openreview.net/pdf?id=jLO4pSi5Pt），显示持续做 VLM 长尾。被引数及引用者暂无可靠可比数据；新发论文的缺引用并非负面证据。
7. **写作迹象**：大篇幅 26 页但 p18-23 附录含附加条件、方差、完整超参，不是简单图表堆砌。p16 的理论 case study 与长尾具体损失/类别不平衡关系较弱；p18 附录数据介绍有个别笔误，p19 表12/17 prompt pool M 消融重复；属于冗余/校对问题，不足以判定整篇灌水。自引异常比例未见证据。

**阅读节段**：p4-6 §3.2/Algorithm 1 读方法；p7-10 §4.1/表2-3 优先看不校准行；p12 表5/6 看泛化；p15 表10 和 p20 表18 看组件与波动；p23 附录 F 复现配置。

## 3. NUCS：略读（数据选择候选路线有价值；理论与统计可信度明显受限）

**论文**：*Non-Uniform Class-Wise Coreset Selection for Vision Model Fine-tuning*。PDF p1 arXiv:2504.13234v2，2025-11-18；arXiv 官方 https://arxiv.org/abs/2504.13234 ，未核到正式刊会录用。适合作为“类间预算×类内难度窗口”的候选基线，不宜把理论命题或加速倍率直接写成已证实事实。

1. **问题价值**：预训练模型对下游类别难度不同，统一全局剪枝会把一些类别大量剔除；p3 图2 的 Food101 applepie 与 edamame EL2N 分布明显错位、附录 p11 图6 全局 50% 硬剪枝只剩 7% applepie，有实测动机。与本项目旧的类间预算/样本选择问题直接相关，但不是多模态视觉证据缺口工作。主实验只有 CIFAR100-LT 一个真正长尾自然图像构造（IR20），其余主要均衡分类集（p6-7），对长尾泛化要克制。
2. **原创性**：类别 EL2N 分数做 5% winsorized 平均，再按 `难度 × 类大小` 分配预算，类内按样本难度的连续窗口挑选，以预训练特征上的 ridge regression 在全训练集选窗口（p4-6 §4）。winsorization、难度得分、按类别预算、最佳窗口都不是新组件，贡献在组装与量化类间难度，原创性中低。论文承认 BWS/CCS-CP 类别比例方法（p3 Related Work）；不能说“首次类别感知”。
3. **实验扎实度**：主实验 5 个数据集（CIFAR10/100、Food101、iNat-mini、CIFAR100-LT），ResNet18/ViT-L，多剪枝率，比较 Random、EL2N、Moderate、CCS、D2、BWS、CCS-CP（p6-8），附录 NIH ChestXray（p12 表7）。p8 表2 CIFAR100-LT IR20、90%剪枝，Random 36.6、CCS-CP 40.4、NUCS-O 46.0（EL2N）；非均匀预算有实质性增益。**但主要强数字是 NUCS-O 网格搜索版，实际 NUCS 位于图4，文字 p7 自称常居第二**；必须分开。p7 表1 iNat-mini ViT-L 80%剪枝 NUCS43.8 vs Random36.8，较好，但 ResNet18 20%剪枝 NUCS40.1 vs CCS40.1、Random39.9，优势小。p13 表8 CIFAR10 ResNet18 90%剪枝 NUCS92.4 < CCS-CP93.4，故“始终最优”不成立。p12 附录 D.2 明言每配置因计算量只跑一次，无方差/显著性，这对小差值特别关键。缺类内窗口、winsorize、预算公式的更充分分离消融；p7 图5只对 NUCS-O 测均匀 vs 非均匀。
4. **可复现性**：p11-12 给 EL2N 预热 ResNet18 4 epoch/ViT-L 3 epoch、模型、epoch、batch、优化器/学习率、窗口端点；但 PDF 与 arXiv 页未给官方代码地址（“未见”而非断言不存在）。具体每次类别划分/随机种子、线性回归计算开销和全流程时间拆分不足。p8 表4 Food101 2.6h→1.3h、iNat 23.3h→11.3h 在70%剪枝，但未清楚将**特征提取、预热打分、11 个窗口的 ridge 拟合与全训练集评估**算进端到端时间；加速主张只能标为“训练计时口径不明”。
5. **结论可信度与理论关键缺口**：p4 Eq(4) 写 `E(t,f0)=f0 Φ((μ0−t)/σ0)+(2f−f0) Φ((t−μ1)/σ1)`；对固定 t，这个关于预算 f0 的函数是**仿射**的，在可行区间通常边界最小。p5 Eq(5)-(7) 解一阶驻点而推出 `f0∝σ0` 为“最优”；二阶上 `E_{f0 f0}=0` 且 `E_{t f0}=a′(t)−b′(t)<0`，Hessian 行列式为负，是鞍点，不是该目标的局部最小。附录 p13 Eq(13)-(18) 加了约束仍称“固定最优 t 时凸”并沿用该驻点，不能修复。这个是基于原式的数学核查，应写作“理论最优证明不成立/存疑”，并不直接否定表2经验效果。另 p4 类别难度混合预训练不足、内在难度与下游样本数，因果分解未测。
6. **发表痕迹**：官方 arXiv 记录 v2，未在可核的正式刊会/期刊查到录用；持续产出及准确被引者/数目缺可确认信息，标“信息不足，需正式发表记录及可信引文索引”，不以预印本身份判水。
7. **写作迹象**：p2 “理论支撑”与 p4-5 的一阶驻点不匹配；p7 对 NUCS 与 NUCS-O 成绩的叙述容易混淆实际方案和网格上界；p8/附录 p12 NIH 说“NUCS-O始终最佳”，但表7 30%时 D2、NUCS、NUCS-O 均 0.803 并列，且 90% NUCS 0.732 < CCS-CP 0.753；这是选择性概括，不等于整篇无价值。未见自引异常证据。

**阅读节段**：p3 §3.2 看现象；p4-6 §4 看预算和类内窗口；p7-8 表1-4 与图5 区分 NUCS 与 NUCS-O；p11-13 附录 B/D/F 看预热成本、单次运行与理论问题。

## 4. RCAP：略读（有广泛实证与代码，长尾加速线可用；鲁棒/零开销表述过满）

**论文**：*RCAP: Robust, Class-Aware, Probabilistic Dynamic Dataset Pruning*。PDF p1、PMLR 官方 https://proceedings.mlr.press/v286/hassan25a.html 核实 UAI 2025，PMLR 286:1648-1662。

1. **问题价值**：动态剪枝可减训练计算，类困难度变化会伤最差类别，真实问题。p6-7 六个公开数据集（CIFAR10/100、ImageNet、Waterbirds、CelebA、iNaturalist），从头训练/迁移/微调三种范式。对于本项目“数据选择与总成本”旧线有比较价值，但处理判别式视觉分类，不涉及文本知识/生成式 VLM。
2. **原创性**：每 epoch 用上一轮类别聚合 loss 算类别保留比例，类内按截断 loss Softmax 概率抽样（p3-5 §3）；类分配、困难样本采样、动态剪枝均已有，组合具体但理论机制不新。p5 Related Work 包括 InfoBatch、RS2、MetriQ。真正有用的设计是低成本类别比例更新和无须完整排序。
3. **实验扎实度**：七个基线（CCS、MetriQ、TDDS、UCB、InfoBatch、RS2 有/无放回），六数据集×4剪枝率，每项 3 seeds，附录 p15 列训练协议和 β 值，公开集而非自家集。p6 表1 iNat 90%剪枝最差类 RCAP68.49±2.74，MetriQ65.14±4.31，很多基线更低；p7 表2 对 iNat 平均83.62全量 vs RCAP82.97，说明保护最差类并未总是提升平均。ImageNet 90% p7 平均 RCAP83.54±0.02 vs RS2无放回83.49±0.03，绝对差仅0.05，不应宣称决定性胜利。p6 ImageNet Worst Group 多个静态基线为0，可能正是完全漏类导致；这是有效的类别覆盖证据，但若要和类比例随机采样比较，论文缺一个**简单“每类保持比例/固定配额 + 随机”动态基线**，缺“只分预算”“只类内 hard-sample”“loss clip”模块分离消融；p8 主要只扫 β。Waterbirds仅当陆/水鸟两个标签、CelebA仅金发/非金发二分类（p6），所谓 Worst Group 是最差类别，没验证属性×背景/性别交叉子群鲁棒性。
4. **可复现性**：p1、PMLR 链接代码 https://github.com/atif-hassan/RCAP-dynamic-dataset-pruning ，仓库公开且为 DataCull 项目；p15 附录 C 给设备 A100、三 seeds（0,27,100）、epoch/batch/优化器/β。p4 Eq(12e) 明确训练前全量数据前向一次取初始损失，p5 又说“无额外计算开销”，至少与该全量扫描矛盾；p6/7 Time 列没有清楚分拆初始化前向、各 epoch 采样与训练，8.69×应视为作者计时口径结果，端到端加速**待确认**。β 每数据集每剪枝率分别选择（p15 表4），算入调参成本会降低实用加速。
5. **结论可信度与理论关键缺口**：p3 Theorem 3.1 定义 `E_{t+1}=Σ_j [p_j/(α_{j,t+1} n_j)]·\tilde E_{j,t+1}`，其中 `\tilde E_{j,t+1}=Σ_{x∈S_{j,t+1}} L(f_{θ_t}(x))`；但 `|S_{j,t+1}|=α_{j,t+1}n_j`，故损失和随 α 和抽样集合变。求导时却把 `\tilde E` 当常数，得 `−p_j\tilde E/(α_j² n_j)`，仅是冻结损失和的替代优化，不是原动态选样的闭式最优。p3 Remark 用上一轮 loss 代替下一轮又加近似，p14 附录 B 上界含未控制的样本替换项。经验提升仍成立于其测试；“闭式最优”“无额外开销”“全面鲁棒”均超范围。p9 自认 β 手调与初期近似不准。
6. **发表痕迹与具体引用**：PMLR 确认 UAI 2025。相同三位作者同会有模型剪枝 *SPvR*（官方 https://proceedings.mlr.press/v286/hassan25b.html），说明效率研究持续。至少核到两篇后续预印本的正文/参考文献引用：*Beyond Loss Values: Robust Dynamic Pruning via Loss Trajectory Alignment* 在 §2/参考[14] 提到 RCAP（https://arxiv.org/html/2604.07306）；*Beyond What to Select: A Plug-and-play Oscillatory Data-Volume Scheduling for Efficient Model Training* 在 §2.2/参考表提到 RCAP（https://arxiv.org/html/2605.14773）。它们属于研究者引用，不代表认可其结论；总引用数未知，需可信引文索引才可报。
7. **写作迹象**：p8-9 Related Work 是按几何/不确定性/loss/边界/梯度/双层/随机等分类的宽泛列表，与关键最强对手的失效原因分析较少。p10-11 同一个 RS2 论文在参考文献以 Okanovic 2024a、2024b 重复，属于编辑冗余。p9 “zero overhead”与 p4 初始化扫描冲突，是具体过度声称。自引比例未见异常，不能仅因夸张文案判全篇灌水。

## 可直接供总报告的“水法”与边界

- **把一阶驻点写成最优预算**：NUCS p4-5 Eq(4)-(7)，附录 p13；这是严肃数学错误，不能因实验好就省略。
- **把冻结替代目标的解写成原动态问题闭式最优**：RCAP p3 Theorem 3.1；应称启发式类别配额。
- **把未测的预训练偏差写成已纠正机制**：MDPR p3 Eq(2)、p9 结论；实际测的是下游准确率。
- **把附加数据/成本藏进“轻量”叙述**：LAMP p6 校准使用未标注新类训练图像（不过论文主表已分列，不能说完全隐藏）；MDPR p9 每轮时间表未计 p14 约3900秒离线生成；NUCS p8 2×时间未拆预热与选择；RCAP p4-5 全量初始化扫描和 p9 零开销相冲突。
- **指标窄化再扩大称“鲁棒”**：RCAP p6 只按类别定义最差组，Waterbirds/CelebA 未做交叉群体；LAMP p8-10 B2N HM/宏F1 无逐尾类覆盖；两篇不等于没有实验价值。
- **验证简单代理而称知识质量可靠**：MDPR p13-14 LLM 按平均 CLIP 相似度 0.001 级差异选取，核验只查格式/关键词，无属性真实及当前图像可见性审计。对本项目尤其要警惕。

**总体边界**：四篇都不是“无正文无实验、可一眼跳过”的论文。LAMP/MDPR 可作为当前 VLM 主线的方法与对照；NUCS/RCAP 更适合保留在数据选择支线。NUCS/RCAP 的理论与速度包装值得严厉批判，但它们的公开基准结果/代码仍给了可检验基线，不能把“某些结论灌水”直接等同于“整篇完全没价值”。
